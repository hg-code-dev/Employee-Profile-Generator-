# Employee Profile Generator

A simple Python script created as part of the freeCodeCamp Python course workshops. This project demonstrates foundational Python programming concepts such as string manipulation, variable assignment, type conversion, string slicing, and f-strings.

## Features

* *String Manipulation & Concatenation:* Combines variables to generate full names and custom employee info strings[cite: 1].
* *Type Conversion:* Converts integers (such as age and years of experience) into strings to concatenate them with descriptive text[cite: 1].
* *F-Strings:* Utilises formatted string literals to cleanly output structured data like employee cards[cite: 1].
* *String Slicing:* Extracts specific sub-strings (such as department codes, year codes, initials, and ID suffixes) from structured company codes[cite: 1].

## Code Overview

The script processes employee details and outputs formatted records:
- *Profile Details:* Full name, address, age, experience, and yearly salary[cite: 1].
- *Code Breakdown:* Slices the company code DEV-2026-JD-001 into its respective metadata components[cite: 1].
